# DD Party: a KDE Plasma 6 global theme

DeskDroid's party look for any KDE Plasma 6 desktop. It uses near-black surfaces,
#990045 magenta, rainbow accents and chamfered corners, with Orbitron for headings
and Chakra Petch for body text.

## What's inside

| Part | Name | Where it shows |
|---|---|---|
| Global theme | DD Party (`org.deskdroid.ddparty`) | System Settings > Colors & Themes > Global Theme |
| Colour scheme | DDParty | all KDE/Qt apps, plus GTK apps through Breeze GTK |
| Plasma style | dd-party | panel, Kickoff, popups, notifications, tooltips, task highlights |
| Window decoration | DDParty (Aurorae) | title bars: chamfered corners, rainbow top line on the active window |
| App style | DDParty (Kvantum) | buttons, tabs, menus, rainbow progress bars and sliders, magenta selection |
| Icons | DD-Party | folders, file types, apps, devices; anything missing falls back to Breeze Dark |
| Wallpaper | DDParty | 1080p up to 4K, ultrawide and phone sizes |
| Splash | DD Party | DeskDroid logo with the 20-segment rainbow bar |
| Konsole | DDParty colours and profile | translucent terminal with rainbow ANSI colours |
| Kate / KWrite / KDevelop | "DD Party" editor theme | syntax colours |
| Fonts | Orbitron, Chakra Petch (SIL OFL) | UI and title bar fonts |

## Install

You need Plasma 6 and Kvantum. The package is called `qt-style-kvantum` on Debian
and Ubuntu, `kvantum` on Arch and Fedora, and `kvantum-qt6` on openSUSE.

```sh
./install.sh --apply            # install for your user and switch to it
./install.sh --apply --layout   # also use DD Party's floating bottom panel (replaces your panels)
./install.sh --apply --no-fonts # keep your current fonts
sudo ./install.sh --system      # install for every user in /usr/share (then pick it per user)
```

Plain `./install.sh` only installs the theme. You can then pick "DD Party" in
System Settings > Colors & Themes > Global Theme. That route doesn't set
Kvantum or the fonts, so use `--apply` to get those, or set them yourself in
Kvantum Manager and in Text & Fonts. Log out and back in once so every app
picks up the style and fonts.

To remove the theme, first switch back with
`plasma-apply-lookandfeel -a org.kde.breezedark.desktop`, then run `./uninstall.sh`
(add `--system` if you installed it that way). Kvantum and the fonts revert
when you choose another theme or font.

## Known limits

- In Dolphin, the status bar text gets shortened ("10 f…ders"). This is a Kvantum
  issue and stock KvArcDark does the same.
- GTK apps (Firefox, GIMP and others) take the colours but keep Breeze shapes.
- Window titles can't be forced to uppercase. KDE has no setting for that.
- The System Settings app icon comes from Breeze, so its own sidebar icons stay correct.
- The Kvantum theme is built on KvArcDark and is GPL. The fonts are SIL OFL
  (licences are in `fonts/`).

## Rebuilding

Everything is generated by the Python scripts in `gen/`, which need Python 3,
Pillow and numpy. The palette lives in `gen/palette.py`. After changing it:

- `KVARC=/usr/share/Kvantum/KvArcDark gen/build.sh` makes the full desktop
  package above in `out/` (KvArcDark comes with `qt-style-kvantum-themes`).
- `gen/native.sh` makes the files DeskDroid's own desktop ships
  (`native/plasma/shell/ddparty` and the DDParty wallpaper); commit those.

## In DeskDroid

DD Party is DeskDroid's default look. The native desktop has no Kvantum,
so apps there are Breeze in DD Party's colours; window borders are DD
Party's Aurorae theme (Aurorae is built for Android in build-deps.sh, and
KWin keeps Breeze in a build without it). The Plasma style, icons, colours,
editor and terminal colours are the same.
NativeDesk.kt sets it for new users and, once, for users still on the old
Breeze Dark default.

GTK programs there get `DD-Party`, Breeze for GTK built in DD Party's
colours (native/plasma/build-deps.sh). On a Plasma desktop, System Settings
does the same for Breeze GTK by itself.

Etherium, DeskDroid's browser, gets the look from
`native/firefox/etherium/chrome/`: its AutoConfig (`theme.js`) registers those
style sheets at startup, so every profile has them, new ones too.
